설치부터 매주 예배 준비까지 — 교회 담당자를 위한 완전 가이드

1
이 프로그램은 무엇인가요? 프로그램 소개

예배PPT 관리 시스템은 매주 예배에 필요한 PowerPoint 파일 3종을 자동으로 만들어 주는 프로그램입니다. 찬송가 번호, 교독문 번호, 성경 본문, 설교 제목 등을 입력하면 슬라이드가 자동으로 생성됩니다. 또한 예배 진행 중 성경·찬송가·교독문·찬양 PPT를 검색창 하나로 즉시 열 수 있어 부드러운 예배 진행이 가능합니다.

📋
예배순서 PPT
worshippt.ppt
예배 순서·찬송·교독문 번호, 설교 제목 등이 담긴 메인 슬라이드. 항목을 클릭하면 해당 PPT로 즉시 이동합니다.
📖
성경 PPT
성경.ppt
설교 제목과 성경 본문 슬라이드. 클릭하면 해당 장·절 성경 PPT로 바로 이동합니다.
📢
광고 PPT
광고.ppt
광고 내용 슬라이드. 내용이 많으면 자동으로 여러 슬라이드로 분할됩니다.
💡
핵심 흐름 (매주 4~5단계): 예배순서 선택 → 내용 입력(이전 값 자동 불러오기) → PPT 생성 → 예배 시작. 예배순서 양식은 최초 1회만 만들면 됩니다.
2
설치 및 초기 설정 최초 1회
설치 전 준비사항 확인
🖥️
운영체제
Windows 10 또는 Windows 11 (64비트)
📊
Microsoft PowerPoint
반드시 설치되어 있어야 합니다(2013 이상 권장, 2024에 최적화)
🌐
Microsoft WebView2 Runtime
프로그램 UI 구동에 필요합니다. 설치 파일에 포함되어 있어 별도 설치 불필요
🔑
인터넷 연결
최초 라이선스 인증 시 1회 필요. 이후 24시간마다 백그라운드 검증(오프라인 사용 가능)
프로그램 설치
1
설치 파일 실행
제공받은 WorshipPPT_Setup.msi 파일을 더블클릭합니다. 저장매체나 컴퓨터의 같은 폴더에 zip파일이 있어야 합니다. Windows 보안 경고가 나타나면 [더 많은 정보] → [실행]을 클릭합니다.
2
설치 진행
[다음] 버튼을 클릭하여 설치를 진행합니다. 설치 경로는 기본값을 권장합니다. 찬송가·성경·교독문 데이터 파일도 함께 자동 설치됩니다.
3
설치 완료
[완료] 버튼을 클릭합니다. 바탕화면 또는 시작 메뉴에서 'WorshipPPT' 아이콘을 확인합니다.
데이터 폴더 구조

설치 후 프로그램이 사용하는 데이터 폴더 구조는 다음과 같습니다. 경로는 설치 위치에 따라 다를 수 있으며, 레지스트리에 자동 저장됩니다.

worshipPPT\ ← 설치 위치
├── bible\ ← 성경 PPT
│ ├── OT\ ← 구약 (Genesis, Exodus … Malachi)
│ └── NT\ ← 신약 (Matthew, Mark … Revelation)
├── hymn\ ← 찬송가 (23.ppt, 100.ppt …)
├── versicle\ ← 교독문 (1.ppt, 2.ppt …)
├── praise\ ← 찬양 PPT (1_제목.ppt, 2_제목.ppt …) → 이 폴더만 유일하게 유저가 사용가능 합니다.
├── templates\ ← 예배순서 양식 (자동 저장)
├── worshipPPT.exe
└── worship_ppt.html
📁
찬양 PPT 추가:찬양 PPT를 직접 만들경우 가능한한 이 프로그램의 빈 슬라이드 만들기를 활용하여 기본 포맷이 들어간 슬라이드를 만든 뒤 이 슬라이드를 이용하여 만들기 바랍니다. 그리고 이렇게 만들어진 파일을praise\ 폴더에 1_제목.ppt, 2_제목.ppt 형식으로 저장하면 검색창에서 /1, /2로 바로 열 수 있습니다.
라이선스 인증

프로그램을 처음 실행하면 라이선스 인증 화면이 나타납니다. 인터넷이 연결된 상태에서 진행하세요.

1
라이선스 키 받기
프로그램 관리자에게 mail을 통하여 라이선스 키를 받습니다. 형식: XXXX-XXXX-XXXX-XXXX
2
키 입력 및 인증
라이선스 입력란에 키를 입력한 뒤 [인증하기]를 클릭합니다. Firebase 서버를 통해 실시간으로 검증됩니다.
3
인증 완료
'인증 성공' 메시지가 나타나면 자동으로 메인 화면으로 이동합니다. 인증 정보는 레지스트리에 안전하게 저장됩니다.
⚠️
주의: 라이선스 키는 PC 1대에만 사용할 수 있습니다.
🔒
오프라인 사용: 인증 후에는 인터넷 없이도 사용할 수 있습니다. 프로그램이 24시간마다 백그라운드에서 자동 재검증하므로 별도로 신경 쓰지 않아도 됩니다.

4
예배순서 만들기 최초 1회 — 이후 재사용

'예배순서'는 매주 반복되는 순서의 틀입니다. 한 번 만들어두면 매주 재사용하므로 처음에만 진행합니다. 주일예배·수요예배 등 여러 양식을 따로 만들어 둘 수 있습니다.

예배순서 만들기 단계
1
예배순서 만들기 탭 클릭
프로그램 상단 탭에서 [예배순서 만들기]를 클릭합니다. 왼쪽에 선택 가능한 항목 목록이 나타납니다.
2
항목 추가
왼쪽 목록에서 항목을 클릭하면 오른쪽 '선택된 순서'에 추가됩니다. 찬송가가 여러 개면 여러 번 클릭합니다.
3
순서 조정
▲ / ▼ 버튼으로 순서를 변경하고, [삭제] 버튼으로 잘못 추가한 항목을 제거합니다.
4
이름 입력 후 저장
하단 이름 입력란에 예배 이름(예: 주일예배)을 입력하고 [저장]을 클릭합니다.
선택 가능한 항목 설명

찬송가번호를 입력하면 해당 찬송가 PPT와 자동으로 연결됩니다 (여러 번 추가 가능)
교독문번호를 입력하면 해당 교독문 PPT와 자동으로 연결됩니다
기도기도자의 이름과 직분을 입력합니다
특송특송하시는 분의 이름과 직분, 또는 단체이름을 입력합니다
성경본문 정보를 입력하면 성경 PPT 해당 절로 바로 이동하며 성경.ppt 생성의 기초가 됩니다(최대 4개 입력 가능)
설교설교 제목 입력란이 생성되고 설교의 제목을 입력하면 성경.ppt 생성의 기초가 됩니다
광고여러 줄의 광고 내용을 입력할 수 있으며, 광고.ppt 생성의 기초가 됩니다. 내용이 많으면 슬라이드가 자동 분할됩니다
✏️ 기타위 목록에 없는 항목을 자유롭게 추가합니다. 클릭하면 항목명 입력 팝업이 열리며, 원하는 이름(예: 헌화, 특별순서, 성찬식)을 직접 입력할 수 있습니다. 입력한 이름이 예배순서 슬라이드에 그대로 표시되며, 링크나 별도 내용 입력 없이 순서에만 나타납니다. 여러 번 추가할 수 있습니다.
💡
팁: 주일예배·수요예배·새벽예배 등 순서가 다른 경우 각각 만들어두면 매주 선택해서 사용할 수 있습니다. 기존 예배순서를 삭제하려면 입력 탭에서 해당 순서 선택 후 [현재 순서 삭제]를 클릭하세요.
5
배경 이미지 설정 선택 사항 — 한 번 설정하면 매주 자동 적용

예배순서·성경·광고 PPT에 배경 이미지를 각각 따로 지정할 수 있습니다. 배경을 설정하면 슬라이드 텍스트 색상이 배경 밝기에 따라 자동으로 흰색 또는 검정으로 조정됩니다.

배경 이미지 설정 방법
1
예배순서 입력 탭 이동
상단 탭에서 [예배순서 입력]을 클릭하고 사용할 예배순서를 선택합니다.
2
배경 이미지 영역 확인
입력 폼 상단에 배경 이미지 영역이 표시됩니다. 예배순서용·성경용·광고용 세 종류를 각각 따로 설정할 수 있습니다.
3
이미지 파일 선택
[이미지 선택] 버튼을 클릭한 뒤 JPG 또는 PNG 파일을 선택합니다. 개별 교회에사 사용하는 이미지가 있다면 백그라운드로 사용 가능합니다. 미리보기가 나타나면 정상 적용된 것입니다.
4
PPT 생성 시 자동 반영
[PPT 생성]을 클릭하면 선택한 배경 이미지가 슬라이드에 자동 적용됩니다. 배경을 없애려면 [삭제] 버튼을 누르면 흰색 배경으로 생성됩니다.
배경 종류 안내
배경 종류적용 대상글자색 자동 설정
예배순서 배경예배 순서 슬라이드배경 밝기에 따라 자동(검정, 흰색, 녹색, 황색)
성경 배경성경 본문 슬라이드배경 밝기에 따라 자동 (밝으면 검정 / 어두우면 흰색)
광고 배경광고 슬라이드배경 밝기에 따라 자동 (밝으면 검정 / 어두우면 흰색)
🎨
자동 글자색: 배경이 어두우면 글자가 자동으로 흰색으로, 밝으면 검은색으로 설정됩니다. 별도로 조정하지 않아도 됩니다.
💾
한 번 설정하면 기억됩니다: 배경 이미지는 저장되어 다음에도 동일하게 적용됩니다. 매주 다시 설정할 필요가 없습니다.
🖼️
권장 이미지: 단순하고 텍스트가 없는 이미지를 권장합니다. 너무 복잡한 이미지는 글자를 읽기 어렵게 만들 수 있습니다.

매주 예배 내용 입력하기 매주 반복

각 행은 실제 파일 존재 여부에 따라 세 가지 상태로 표시됩니다.

행 상태표시 내용클릭 동작
파일 있음 (정상)번호 · 제목 · ▶ 화살표 표시. 삭제 모드에서는 화살표 대신 [삭제] 버튼 표시.해당 번호의 찬양 PPT를 슬라이드쇼로 실행합니다.
파일 없음 (빈 슬롯)번호 · — 표시. 반투명하게 표시됩니다.클릭해도 동작 없음.
삭제된 슬롯번호 · — 삭제됨 — 표시. 번호 자리는 유지됩니다.클릭해도 동작 없음.
💡
검색 기능: 목록 상단 검색창에 번호 또는 제목 일부를 입력하면 실시간으로 필터링됩니다. ESC 키로 검색어를 지울 수 있습니다.
실제 파일과의 자동 교차 검증

찬양목록을 열 때마다 praise\ 폴더를 스캔하여 등록 정보와 대조합니다. 다음 세 가지 상황이 자동으로 처리됩니다.

①
등록됐으나 파일이 없는 경우
프로그램 외부에서 파일을 직접 삭제한 경우입니다. 해당 번호는 자동으로 빈 슬롯(삭제됨)으로 처리되어 번호 순서에 빈 자리가 남습니다.
②
파일은 있으나 등록 정보가 없는 경우
praise\ 폴더에 외부에서 파일을 직접 복사한 경우입니다. 해당 번호가 자동으로 등록됩니다. 저장된 제목 정보가 있으면 복원하고, 없으면 찬양 N번으로 임시 등록합니다.
③
삭제 표시됐으나 파일이 다시 생긴 경우
삭제 후 같은 번호로 새 파일을 만들거나 복사한 경우입니다. 삭제 표시가 자동으로 해제되고 정상 등록 상태로 복원됩니다.
⚠️
오프라인 시: WorshipPPT 앱이 실행 중이 아니면 파일 스캔을 건너뜁니다. 이 경우 동기화 상태에 ⚡ 오프라인이 표시되며, 마지막으로 저장된 목록 데이터를 기준으로만 표시합니다.
찬양 파일 삭제하기

찬양목록에서 직접 파일을 삭제할 수 있습니다. 삭제된 번호는 빈 슬롯으로 남아 이후 번호들의 순서에 영향을 주지 않습니다.

1
찬양목록 열기
메인 메뉴에서 🎵 찬양목록을 클릭하여 목록 화면을 엽니다.
2
삭제 모드 켜기
헤더 오른쪽의 🗑 삭제 모드 버튼을 클릭합니다. 버튼이 빨간색으로 활성화되고 각 곡 행 오른쪽에 [삭제] 버튼이 나타납니다.
3
삭제할 곡의 [삭제] 버튼 클릭
삭제할 찬양 행의 오른쪽 [삭제] 버튼을 클릭합니다. 삭제 모드일 때는 행을 클릭해도 슬라이드쇼가 실행되지 않습니다.
4
확인 창에서 최종 승인
번호·제목·경고 문구가 포함된 확인 창이 표시됩니다. [확인]을 누르면 파일이 즉시 삭제됩니다. [취소]를 누르면 아무 변화가 없습니다.
5
삭제 결과 확인
삭제가 완료되면 해당 번호 행이 — 삭제됨 — 슬롯으로 바뀌고, 헤더 상태 표시가 🗑 N번 삭제됨으로 업데이트됩니다.
6
삭제 모드 끄기
삭제 작업이 끝나면 🗑 삭제 모드 ON 버튼을 다시 클릭하여 일반 모드로 돌아옵니다. 이후 곡을 클릭하면 슬라이드쇼가 정상 실행됩니다.
🗑️
주의 — 복구 불가: 삭제된 파일은 휴지통에 가지 않고 즉시 영구 삭제됩니다. 중요한 파일은 미리 다른 곳에 백업해 두세요.
📌
빈 슬롯 유지: 삭제된 번호는 — 삭제됨 —으로 표시되어 빈 자리를 유지합니다. 같은 번호로 새 파일을 만들면 빈 슬롯이 자동으로 채워집니다.

Windows 탐색기에서 C:\worshipPPT\praise\ 폴더에 파일을 직접 추가하거나 삭제할 수도 있습니다. 이 경우 다음 규칙을 따르면 찬양목록과 자동으로 동기화됩니다.

상황처리 방법
파일 직접 복사파일명을 숫자_제목.pptX 형식으로 저장하세요. 다음에 찬양목록을 열면 자동으로 목록에 등록됩니다. 제목은 찬양 N번으로 임시 등록되며, 찬양 PPT 만들기에서 같은 번호로 다시 저장하면 정확한 제목이 반영됩니다.
파일 직접 삭제탐색기에서 파일을 지우면 다음에 찬양목록을 열 때 해당 번호가 빈 슬롯으로 자동 처리됩니다.
파일 이름 변경파일명은 반드시 숫자_제목으로 만들어야 합니다. 숫자_제목이 아닌 파일은 목록에 표시되지 않습니다.

상황 ① 가사가 있는 찬양 만들기

가사를 입력하면 페이지별로 자동 분할되는 텍스트 찬양 PPT를 만드는 방법입니다.

1
검색로고 선택
검색로고1(밝은 색) 또는 검색로고2(어두운 색) 중 배경 이미지와 대비가 잘 되는 것을 선택합니다.
어두운 배경 → 로고1 (흰색 계열) / 밝은 배경 → 로고2 (어두운 색 계열) 권장.
2
배경 이미지 선택 (선택 사항)
[이미지 선택] 버튼을 클릭하여 JPG, PNG 배경 파일을 불러옵니다.
불러온 이미지는 미리보기로 확인할 수 있습니다. 배경 없이 만들려면 이 단계를 건너뜁니다(흰 배경으로 생성됨).
3
슬라이드 내용 → "가사 입력" 선택
슬라이드 내용 영역에서 ✏️ 가사 입력 버튼이 선택된 상태인지 확인합니다. (기본값)
4
찬양 제목 입력
제목 입력란에 찬양 이름을 입력합니다. 예: 야곱의 축복
이 제목이 파일명과 찬양목록에 사용됩니다.
5
가사 입력
가사 텍스트 입력창에 내용을 입력합니다.
📌 슬라이드 나누기: 빈 줄(Enter 두 번)을 넣으면 그 위치에서 새 슬라이드로 나뉩니다.
📌 자동 줄바꿈: 한 줄에 약 18자 이상이면 자동 줄바꿈됩니다. 자연스럽게 끊기도록 적당한 위치에서 Enter를 추가하면 더욱 깔끔합니다.
예시:
야곱의 축복이 내게 임하네
아브라함의 축복 내게 임하네

(빈 줄 → 다음 슬라이드)

하나님의 축복이 내게 임하네
예수 그리스도의 축복 임하네
6
폰트 색상 선택
검정·흰색·노란색·녹색 중 배경과 대비가 잘 되는 색을 선택합니다.
7
파일명 입력
파일명 입력란에 번호_제목 형식으로 입력합니다.
예: 1_야곱의 축복 → 1_야곱의 축복.pptx로 저장됩니다.
번호는 찬양목록에서 순서를 결정하며, 입력창 오른쪽에 번호 사용 가능 여부(✅/⚠️)가 표시됩니다.
8
저장 폴더 확인
기본 경로는 C:\worshipPPT\praise\입니다. 특별한 이유가 없으면 변경하지 않습니다.
9
PPT 저장 클릭
하단 [💾 PPT 저장] 버튼을 클릭하면 저장이 완료됩니다. 완료 알림이 표시되고 찬양목록에 즉시 등록됩니다.
✅
저장된 파일은 예배 중 검색창에서 번호 입력으로 즉시 슬라이드쇼를 열 수 있습니다.
상황 ② 빈 슬라이드 만들기

빈 슬라이드를 만들거나 빈 슬라이드에 악보 이미지를 삽입하는 방법입니다. 두 가지 방식을 선택할 수 있습니다.

📌
악보 찬양의 두 가지 방식
방식 A — 빈 슬라이드를 만들어 저장한 후 직접 PowerPoint에서 악보 이미지를 삽입
방식 B — 빈 슬라이드에 기존 악보 PPT 파일을 "참고 파일"로 지정하여 악보를 자동 추출·삽입

방식 A — 빈 슬라이드 만들기 후 직접 편집

1
검색로고 선택
배경을 생각하여 어두운 배경이면 로고1을 밝은 배경이면 로고2를 선택합니다.
2
배경 이미지 선택
컴퓨터나 외장장치에서 원하는 배경을 선택합니다. 복잡하지 않은 단순한 배경을 추천합니다.
3
내용 입력에서 "빈 슬라이드" 선택
슬라이드 내용 영역에서 📄 빈 슬라이드 버튼을 클릭합니다. 페이지 수 입력창이 나타납니다.
4
페이지 수 지정
악보 슬라이드가 몇 장인지 입력합니다. 빈 슬라이드만 만들경우 만들 찬양의 전체 페이지를 고려하여 만듭니다.
5
로고·배경 선택 후 저장
위의 가사 찬양과 동일하게 로고·배경·파일명을 설정하고 [💾 PPT 저장]을 클릭합니다.
6
PowerPoint에서 악보 삽입
저장된 파일(C:\worshipPPT\praise\번호_제목.pptx)을 PowerPoint로 열어 각 슬라이드에 악보 이미지를 삽입합니다. 삽입 후 PowerPoint에서 직접 저장합니다.

방식 B — 참고 파일에서 악보 자동 추출·삽입

기존 악보 PPT 파일(참고 파일)에서 악보 이미지를 자동으로 추출하여 새 파일에 삽입합니다. 수작업 없이 빠르게 악보 찬양을 만들 수 있습니다.

3
내용 입력에서 "빈 슬라이드" 선택
슬라이드 내용 영역에서 📄 빈 슬라이드 버튼을 클릭합니다. 페이지 수 입력창이 나타납니다. "빈 슬라이드 + 악보"일 경우 참고 파일을 선택하면 참고 파일 선택의 하단에 이 찬양이 몇장의 슬라이드로 구성되어 있는지 표시 되므로 이것을 참고하여 슬라이드 페이지 수를 정하면 됩니다.
4
악보 참고 파일 불러오기
🎵 악보 참고 파일 영역에서 [📂 파일 선택]을 클릭하여 기존 악보가 들어 있는 PPT/PPTX 파일을 선택합니다.
파일이 로드되면 ✅ 로드 완료 — N장이 표시됩니다.
5
로고·배경 선택 후 저장
로고·배경·파일명을 설정하고 [💾 PPT 저장]을 클릭하면, 악보가 자동으로 삽입된 완성 파일이 저장됩니다.
💡
악보 추출 방식: 참고 파일의 각 슬라이드에서 가장 큰 이미지(p:pic)를 자동으로 찾아 추출합니다. 로고는 자동으로 제외됩니다. 별도 지정 없이도 악보가 정확하게 추출됩니다.

STEP 1 — 수정할 찬양 선택

1

예: 야곱을 입력하면 제목에 "야곱"이 포함된 찬양만 표시됩니다.

목록에서 찬양 행 클릭

STEP 4 — 배경 이미지 변경 (선택)

버튼설명

🗑️ 배경 제거기존 배경 이미지를 완전히 삭제하고 흰 배경으로 저장합니다.
✔ 기존 유지중기존 배경 이미지를 변경 없이 유지합니다. (기본값)

🖼️ 배경 이미지 미리보기 상세 설명

배경 이미지를 새로 선택하면 버튼 오른쪽에 150×94픽셀 크기의 썸네일 미리보기가 나타납니다. 이 미리보기는 실제 슬라이드 비율(16:9)에 맞춰 표시됩니다. 썸네일 아래에는 선택한 파일 이름이 함께 표시되어 어떤 파일이 선택됐는지 확인할 수 있습니다.

예
"야곱의 축복" 배경을 새 이미지로 교체하는 경우
1. [이미지 변경] 버튼(파란색)을 클릭합니다.
2. 탐색기가 열리면 교체할 이미지 파일(예: 배경_봄.jpg)을 선택합니다.
3. 버튼 오른쪽에 선택한 이미지의 썸네일이 나타납니다. 여기서 이미지가 원하는 것이 맞는지 확인합니다.
4. 아울러 🗑️ 배경 제거 버튼과 ✔ 기존 유지중 버튼이 함께 표시됩니다.

STEP 5-1 — 악보 위치 및 배율 수정 (악보 찬양 전용)

악보 이미지의 슬라이드 내 위치(X/Y)와 크기(배율%)를 조정합니다. 악보 파일일 때만 활성화됩니다. 텍스트 찬양 파일은 이 버튼이 회색으로 비활성 표시됩니다.

💡
100% 기준: 배율 100%는 항상 참고 파일에서 처음 삽입 당시의 원본 크기를 기준으로 합니다. 예를 들어 50%로 저장했다가 나중에 다시 100%로 바꾸면 처음 삽입 당시의 원본 크기로 돌아갑니다.

📐 악보 위치 및 배율 수정하기 — 사용 절차

1
[📐 악보 위치 및 배율 수정하기] 버튼 클릭
버튼을 클릭하면 위치/배율 입력 패널이 아래로 열립니다. 패널 상단에는 📋 페이지 통합 수정과 📄 페이지 분리 수정 두 가지 모드 버튼이 있습니다.
2
수정 모드 선택
📋 페이지 통합 수정 (기본값): 모든 슬라이드에 동일한 X/Y/배율을 일괄 적용합니다. 일반적인 경우 이 모드를 사용합니다.
📄 페이지 분리 수정: 1페이지와 나머지 페이지(2페이지 이후 전체)에 서로 다른 값을 적용합니다. 1페이지(예: 제목+전주 악보)의 크기가 나머지와 다를 때 사용합니다.
3
현재 위치와 배율 확인
입력란 아래에 회색 배경의 읽기 전용 입력란이 표시됩니다. 여기에 파일에 현재 저장된 X/Y/배율 값이 표시됩니다. 이 값을 참고하여 어느 방향으로 얼마나 조정할지 판단합니다.
예: 현재 배율이 50%로 표시되어 있고 악보가 너무 작다면, 입력란에 80 또는 100을 입력하여 키울 수 있습니다.
4
X / Y / 배율 값 입력
X (좌 여백, cm): 슬라이드 왼쪽 끝에서 악보까지의 거리(cm). 0이면 왼쪽 끝에 붙습니다.
Y (상 여백, cm): 슬라이드 위쪽 끝에서 악보까지의 거리(cm). 0이면 위쪽 끝에 붙습니다.
크기 배율 (%): 원본 악보 대비 비율. 100이면 원본 크기, 50이면 절반 크기, 150이면 1.5배 크기입니다.

📋 페이지 통합 수정 vs 📄 페이지 분리 수정 비교

모드설명사용 시기
📋 페이지 통합 수정모든 슬라이드에 동일한 X/Y/배율을 적용합니다. (기본값)모든 악보 크기와 위치가 같을 때
📄 페이지 분리 수정1페이지와 나머지 페이지에 각각 다른 값을 설정합니다.1페이지 악보(제목·전주 등)와 나머지 악보 크기가 다를 때

📌 현재 위치와 배율 읽는 방법 — 실전 예시

예1
악보가 오른쪽으로 치우쳐 있을 때
현재 위치 표시가 X: 4.5 cm, Y: 0 cm, 배율: 100%라고 표시됩니다.
악보가 슬라이드 왼쪽 기준으로 4.5cm 오른쪽에 있다는 뜻입니다.
왼쪽 끝으로 붙이려면 X를 0으로 변경 후 저장합니다.
예2
악보가 너무 작을 때 (배율 50% → 100%로 복원)
현재 위치 표시가 X: 0 cm, Y: 0 cm, 배율: 50%로 표시됩니다.
배율을 100으로 바꾸고 저장하면 처음 삽입 당시 원본 크기로 복원됩니다.
예3
악보를 슬라이드 중간 아래쪽으로 옮기고 싶을 때
슬라이드 세로 크기는 약 19.05cm(16:9 기준)입니다.
악보를 위에서 7cm 아래에 놓으려면 Y를 7로 입력하면 됩니다.

STEP 6 — 폰트 색상 변경 (선택)

가사 텍스트의 색상을 변경합니다. 배경 이미지의 밝기에 맞게 대비가 잘 되는 색상을 선택하세요.

색상 버튼설명추천 상황
● 검은색텍스트를 검은색으로 표시합니다.흰색 또는 밝은 배경
● 흰색텍스트를 흰색으로 표시합니다.어두운 배경 이미지
● 노란색텍스트를 노란색으로 표시합니다.어두운 배경에서 강조 효과
● 녹색텍스트를 녹색으로 표시합니다.어두운 배경에서 자연 느낌
✕ 없음색상을 변경하지 않고 기존 색상 그대로 유지합니다.(기본값)
💡
폰트 색상은 선택한 버튼이 파란 테두리로 강조 표시됩니다. 기본값은 ✕ 없음으로, 기존 색상이 그대로 유지됩니다.
STEP 7 — 수정 후 저장

모든 수정이 끝나면 하단의 🔄 수정 후 저장 버튼(주황색)을 클릭합니다.

1
저장 폴더 확인
저장 버튼 위의 📁 저장 폴더 경로를 확인합니다. 기본값은 C:\worshipPPT\praise\입니다. 다른 폴더에 저장하려면 [📂 폴더 선택] 버튼으로 변경합니다. 특별한 이유가 없으면 기본 경로를 그대로 사용하세요.
2
🔄 수정 후 저장 버튼 클릭
버튼을 클릭하면 잠시 처리가 진행된 후 완료 알림 창이 표시됩니다. 알림 창에는 번호·제목·저장 경로가 표시됩니다. 번호나 제목을 변경했다면 변경 전후가 함께 표시됩니다. [확인]을 클릭하면 저장이 완료됩니다.
3
저장 완료 후 자동 초기화
저장이 완료되면 수정 패널이 자동으로 초기화되고 찬양 선택이 해제됩니다. 찬양 목록도 즉시 업데이트되어 변경 내용이 반영됩니다. 수정된 파일은 예배 중 검색창에서 바로 사용할 수 있습니다.
✅
저장 완료 후 찬양목록에 즉시 반영됩니다. 예배 중 검색창에서 번호를 입력하면 수정된 내용이 바로 적용된 슬라이드쇼가 열립니다.
상황별 수정 시나리오 완전 정리

🔤 시나리오 A — 가사 오타를 수정하고 싶어요

예시: "야곱의 축복" 2절에서 "예수 그리스도의 축복 임하네"가 "예수 그리스도의 죽복 임하네"로 잘못 입력된 경우

1
목록에서 "야곱의 축복" 클릭
검색창에 "야곱"을 입력하면 빠르게 찾을 수 있습니다. 클릭하면 수정 패널이 열립니다.
2
슬라이드 내용 → [✏️ 내용 수정하기] 클릭
편집창이 열리고 기존 가사 전체가 입력창에 표시됩니다. "죽복"을 찾아 "축복"으로 수정합니다.
3
나머지는 그대로 두고 [🔄 수정 후 저장] 클릭
로고·배경·폰트 색상은 기본값(변경 없음)으로 두면 기존 상태가 그대로 유지됩니다. 저장 완료 알림이 뜨면 [확인]을 클릭합니다.

🖼️ 시나리오 B — 배경 이미지를 다른 것으로 교체하고 싶어요

예시: "주님의 은혜" 찬양의 배경을 기존 이미지에서 새 봄 이미지로 교체하는 경우

1
목록에서 "주님의 은혜" 클릭
찬양을 선택하면 수정 패널이 열립니다.
2
배경 이미지 → [이미지 변경] 클릭 → 새 이미지 선택
탐색기에서 교체할 이미지(예: 봄배경.jpg)를 선택합니다. 오른쪽에 썸네일 미리보기가 나타납니다. 이미지가 원하는 것이 맞는지 확인합니다.
3
슬라이드 내용·로고는 기본값으로 두고 [🔄 수정 후 저장] 클릭
가사·로고는 그대로 유지됩니다. 저장 후 찬양목록에서 해당 찬양을 실행하여 새 배경이 잘 적용됐는지 확인합니다.

🔢 시나리오 C — 번호를 바꾸고 싶어요 (예: 15번 → 3번)

예시: 자주 사용하는 "야곱의 축복"을 15번에서 빠른 검색을 위해 3번으로 변경하는 경우

1
목록에서 15번 "야곱의 축복" 클릭
수정 패널이 열리면 녹색 카드에 "번호: 15, 제목: 야곱의 축복"이 표시됩니다.
2
번호 입력란의 값을 15 → 3으로 변경
3번이 이미 사용 중이라면 입력란 아래에 ⚠️ 경고가 표시됩니다. 기존 3번 파일을 덮어쓰게 되므로 주의하세요. 덮어쓰기를 원하지 않으면 다른 빈 번호를 사용하세요.
3
[🔄 수정 후 저장] 클릭
저장되면 3_야곱의 축복.pptx로 새 파일이 생기고 15_야곱의 축복.pptx는 자동으로 삭제됩니다. 이제 예배 중 /3으로 바로 호출할 수 있습니다.

🎵 시나리오 D — 악보가 너무 작게 나와요. 크게 하고 싶어요

예시: "주 하나님 지으신 모든 세계" 악보가 슬라이드의 절반 크기(50%)로만 표시되는 경우

1
목록에서 해당 찬양 클릭
악보 파일이 선택되면 [📐 악보 위치 및 배율 수정하기] 버튼이 주황 테두리로 활성화됩니다.
2
버튼 클릭 → 현재 위치와 배율 확인
입력창 아래 회색 읽기 전용 란에 현재 값이 표시됩니다. 예: X: 0 cm, Y: 0 cm, 배율: 50%. 배율이 50%이므로 악보가 원본의 절반 크기입니다.
3
크기 배율 입력란에 100 입력
배율 입력란의 값을 50에서 100으로 변경합니다. X·Y는 0 그대로 두면 됩니다.

[🔄 수정 후 저장] 클릭
저장하면 모든 슬라이드의 악보가 원본 크기(100%)로 표시됩니다.

🎼 시나리오 E — 1페이지 악보는 작게, 나머지는 크게 하고 싶어요

예시: 1페이지에는 제목과 전주 악보(작게), 2페이지 이후에는 본 절 악보(크게)를 표시하고 싶은 경우

1
해당 찬양 선택 → [📐 악보 위치 및 배율 수정하기] 클릭

2
[📄 페이지 분리 수정] 클릭
두 개의 입력 영역이 열립니다: 📄 1페이지와 📄 나머지 페이지(2페이지 이후 전체).
3
1페이지: 배율 60%, 나머지: 배율 100% 입력 후 저장
1페이지 배율 입력란에 60, 나머지 페이지 배율 입력란에 100을 입력합니다. X·Y는 둘 다 0으로 두면 됩니다. 저장하면 1페이지만 60% 크기, 2페이지 이후는 100% 크기로 저장됩니다.

🎨 시나리오 F — 가사 색상이 배경에 묻혀 잘 안 보여요

예시: 어두운 배경 이미지를 새로 설정했는데 기존 검은색 가사가 잘 보이지 않는 경우

1
해당 찬양 선택

흰색 버튼에 파란 테두리가 생기면 선택된 것입니다. 어두운 배경에는 흰색이 가장 잘 보입니다.
3
[🔄 수정 후 저장] 클릭
저장 후 찬양목록에서 해당 찬양을 실행하여 가사 색상이 배경과 잘 대비되는지 확인합니다.
수정 결과 확인하기 — 미리보기 사용법

배경 이미지나 폰트 색상을 바꾼 경우, 저장 후 실제 슬라이드에서 결과를 눈으로 확인하는 것이 좋습니다. WorshipPPT에는 두 가지 미리보기 방법이 있습니다.

방법 ① 배경 이미지 썸네일 미리보기 (저장 전 확인)

배경 이미지를 새로 선택하면 [이미지 변경] 버튼 오른쪽에 즉시 썸네일이 표시됩니다. 이 미리보기는 저장 전에 어떤 이미지가 선택됐는지 확인하는 용도입니다.

1
썸네일 확인
선택한 이미지가 150×94 픽셀 크기의 썸네일로 표시됩니다. 이미지 아래에 파일명이 함께 표시됩니다.
2
다른 이미지로 바꾸려면
[이미지 변경] 버튼을 다시 클릭하여 다른 파일을 선택하면 썸네일이 즉시 교체됩니다.
3
선택을 취소하려면
[✔ 기존 유지중] 버튼을 클릭하면 새로 선택한 이미지가 취소되고 기존 배경이 유지됩니다.
📌
썸네일 미리보기는 이미지 구성과 색감만 확인하는 도구입니다. 실제 슬라이드에서는 배경이 전체 화면 크기로 확대되어 표시되기 때문에 최종 결과는 저장 후 슬라이드쇼에서 확인하는 것이 정확합니다.

방법 ② 찬양목록에서 슬라이드쇼 실행 (저장 후 확인)

저장이 완료된 후, 메인 메뉴의 🎵 찬양목록에서 해당 찬양을 클릭하면 실제 PowerPoint 슬라이드쇼가 바로 실행됩니다. 이것이 가장 정확한 최종 확인 방법입니다.

1
저장 완료 알림에서 [확인] 클릭
수정 후 저장이 완료되면 알림 창이 표시됩니다. [확인]을 누르면 패널이 초기화됩니다.
2
메인 메뉴 → 🎵 찬양목록 진입
메인 메뉴로 돌아가 🎵 찬양목록 카드를 클릭합니다.
3
수정한 찬양 행 클릭 → 슬라이드쇼 실행
찬양목록에서 수정한 찬양 행을 클릭하면 PowerPoint 슬라이드쇼가 즉시 실행됩니다. 배경 이미지·가사·폰트 색상 등 모든 수정 내용이 실제 슬라이드에 어떻게 표시되는지 확인할 수 있습니다. ESC 키를 누르면 슬라이드쇼가 종료됩니다.
✅
실제 슬라이드쇼 미리보기 순서 요약: 기존 찬양 수정 → 수정 후 저장 → 찬양목록 → 해당 찬양 클릭 → 슬라이드쇼 확인 → ESC로 종료. 이 순서로 확인하면 예배 당일 전에 미리 결과를 점검할 수 있습니다.
수정 시 주의사항
⚠️
외부 PPT 파일 가사 수정: 이 프로그램으로 만들지 않은 외부 PPT 파일은 가사 자동 인식이 되지 않을 수 있습니다. 이 경우 새로 만들기 탭에서 같은 번호로 새 파일을 만들어 가사를 직접 입력하거나, PowerPoint에서 직접 편집하세요.

💡
주요 활용 예시: 반주자·성가대 지휘자가 태블릿으로 현재 슬라이드를 확인하거나, 예배 보조자가 스마트폰에서 찬양을 빠르게 열 수 있습니다.
연결 방법 — QR코드 (권장)

가장 간편한 방법입니다. PC에서 QR코드를 표시하고 모바일 기기로 스캔하면 자동으로 접속됩니다.

1
PC와 모바일을 같은 Wi-Fi에 연결
PC와 모바일 기기가 동일한 공유기(Wi-Fi)에 연결되어 있어야 합니다. 모바일 데이터(LTE/5G)로는 접속되지 않습니다.
2
WorshipPPT 앱에서 📱 버튼 클릭
앱 우측 상단(또는 메인 메뉴)의 📱 모바일 미러 버튼을 클릭합니다. QR코드 팝업이 열리며 접속 URL이 함께 표시됩니다.
3
모바일로 QR코드 스캔
스마트폰이나 태블릿 카메라로 QR코드를 스캔합니다. 브라우저에서 자동으로 미러 화면이 열립니다. 모바일이 접속되면 QR 팝업이 자동으로 닫힙니다.
📲
QR코드 스캔 방법: iPhone은 기본 카메라 앱, Android는 카메라 앱 또는 QR 스캐너 앱으로 스캔하면 됩니다. 별도 앱 설치 없이 브라우저만으로 사용 가능합니다.
연결 방법 — 직접 URL 입력

QR 스캔이 불편한 경우 모바일 브라우저에서 직접 주소를 입력할 수 있습니다.

1

PC에서 명령 프롬프트(CMD)를 열고 ipconfig를 입력하면 IPv4 주소를 확인할 수 있습니다. 예: 192.168.1.10. 또는 QR 팝업에 표시된 URL을 확인합니다.
2
모바일 브라우저에서 주소 입력
모바일 브라우저 주소창에 http://PC의IP:27271/mirror 를 입력합니다.
예: http://192.168.1.10:27271/mirror
🔗
IP 자동 기억: 한 번 접속하면 IP 주소가 기기에 저장되어 다음에는 자동으로 연결됩니다. IP가 바뀐 경우에만 새로 입력하면 됩니다.
연결 방법 — 파일로 저장하여 사용 (오프라인 접속용)

QR 팝업에서 [📥 mirror.html 다운로드] 버튼을 누르면 mirror.html 파일을 기기에 저장할 수 있습니다. 저장한 파일을 열면 서버 IP를 입력하는 팝업이 표시되어 접속합니다. Wi-Fi가 같다면 파일 하나로 여러 기기에서 사용할 수 있습니다.

⚠️
파일 사용 시 주의: 파일을 기기에 저장한 경우, PC의 IP가 바뀌면 파일을 열 때 팝업에서 새 IP를 다시 입력해야 합니다. QR코드 방식(브라우저 직접 접속)이 가장 편리합니다.

데이터 폴더의 hymn\ 폴더에 해당 번호의 PPT 파일이 있는지 확인하세요. 파일명은 번호.ppt 형식이어야 합니다. 예) 23.ppt
입력성경 본문 형식이 어떻게 되나요?▼
책 약자 + 장:시작절~끝절 형식으로 입력합니다.
예) 요 3:16~17  |  창 1:1  |  시 23:1~6
장만 입력하려면: 요 3
여러 본문: 요 3:16,롬 8:1 (쉼표로 구분, 최대 4개)
사용예배순서를 잘못 만들었어요. 다시 만들 수 있나요?▼
입력 탭에서 해당 예배순서를 선택한 뒤 [현재 순서 삭제] 버튼으로 삭제하고, 예배순서 만들기 탭에서 새로 만들면 됩니다.
라이선스PC를 새로 샀는데 라이선스 인증이 안 돼요.▼
라이선스 키는 1대의 PC에만 등록됩니다. PC를 교체하셨다면 개발자(drimsw@gmail.com)에게 이메일로 기존 라이선스 키와 사유를 알려주시면 이전 처리를 도와드립니다.
모바일QR코드를 스캔했는데 페이지가 열리지 않아요.▼
다음을 순서대로 확인하세요.
① PC와 모바일 기기가 같은 Wi-Fi에 연결되어 있는지 확인합니다. 모바일 데이터(LTE/5G)로는 접속되지 않습니다.
② PC에서 WorshipPPT 앱이 실행 중인지 확인합니다. 앱이 종료되어 있으면 서버가 꺼집니다.
③ PC 방화벽이 포트 27271을 차단하고 있을 수 있습니다. Windows 방화벽 설정에서 해당 포트를 허용하거나, 개발자에게 문의하세요.
모바일모바일 화면에 슬라이드가 표시되지 않고 "슬라이드쇼 대기 중" 메시지만 나와요.▼
PC에서 슬라이드쇼가 아직 시작되지 않은 상태입니다. WorshipPPT 앱에서 [예배 시작] 버튼을 클릭하여 슬라이드쇼를 실행하면 모바일 화면에 자동으로 미러링이 시작됩니다.
모바일예배 중간에 모바일 화면이 꺼졌다 켜지면 동기화가 깨져요.▼
화면이 꺼진 후 다시 켜지면 자동으로 서버에 현재 슬라이드 정보를 요청하여 동기화합니다. 잠시(1~2초) 기다리면 자동 복구됩니다. 자동 복구가 안 되는 경우 페이지를 새로 고침하세요.
화면이 자주 꺼지는 것이 불편하다면 기기 설정에서 화면 자동 잠금 시간을 길게 설정하거나, 화면 자동 끄기를 해제하세요.
모바일모바일 캐시 저장 중 중간에 멈췄어요.▼
캐시 저장은 언제든 중단할 수 있으며, 다시 시작하면 이미 저장된 슬라이드는 건너뛰고 이어서 받습니다(이어받기). 성경 전권은 약 2GB 이상이므로 Wi-Fi 환경이 안정적인 상태에서 저장하는 것을 권장합니다.
사용광고가 너무 많아서 한 슬라이드에 안 들어가요.▼
광고 내용이 많으면 자동으로 여러 슬라이드로 분할됩니다. 예배 시작 후 슬라이드쇼에서 클릭하거나 방향키로 다음 슬라이드로 이동하면 됩니다.
사용찬양 PPT를 추가하려면 어떻게 하나요?▼
두 가지 방법이 있습니다.
① 찬양 PPT 만들기 메뉴에서 제목·가사·배경을 입력하고 파일명을 숫자_제목(1_제목.pptX, 68_제목.pptX 등)로 저장하면 찬양목록에 자동 등록됩니다.
② 찬양 PPT 만들기 메뉴에서 빈 슬라이드를 만들면 검색과 하단의 페이지 자동가기 기능이 탑재된 빈 슬라이드를 얻을 수 있습니다. 이 슬라이드를 이용하여 악보가 있는 그림을 옮겨넣기로 작업하시면 모든 기능이 활성화된 찬양 PPT를 만들 수 있습니다.
설정검색로고는 어떻게 바꾸나요? ▼
예배순서 입력 탭 상단의 🏷️ 검색로고 선택 영역에서 두 가지 로고 중 하나를 클릭하여 선택합니다. 어두운 배경에는 검색로고1(밝은 색), 밝은 배경에는 검색로고2(어두운 색)를 권장합니다. 선택 후 PPT를 재생성하면 적용됩니다. *개 교회의 로고를 원하시는 경우 별도의 추가 비용이 발생합니다.
오류인터넷이 없을 때 프로그램이 실행되지 않아요.▼
인터넷이 없어도 정상적으로 실행됩니다. 라이선스 인증 정보가 레지스트리에 저장되어 있어 오프라인에서도 사용할 수 있습니다. 다만 최초 인증은 인터넷 연결이 필요합니다.
검색제목을 입력했는데 "결과가 없습니다"라고 나와요.▼
다음을 확인해 보세요.
① 찬양·찬송가 제목: praise\ 또는 hymn\ 폴더에 해당 파일이 있는지 확인합니다. 찬송가는 21세기 찬송가 645장 기준으로 제목이 내장되어 있습니다.
② 성경 본문: 앱을 켠 지 얼마 안 됐다면 성경 인덱스가 아직 준비 중일 수 있습니다. 메시지에 "인덱스 준비 중" 안내가 표시되면 약 30초~1분 후 다시 시도하세요.
③ 공백·오타: 공백이 다소 달라도(예: "온세상위하여" vs "온 세상 위하여") 자동으로 인식합니다. 하지만 완전히 다른 단어라면 결과가 없을 수 있습니다.
검색성경 본문 검색이 너무 느려요 / 결과가 아무것도 안 나와요.▼
성경 본문 검색은 앱 시작 시 백그라운드에서 성경 전권 파일을 인덱싱합니다. 이 작업이 완료되기 전에는 성경 결과가 표시되지 않습니다. 인덱싱 완료까지 약 30초~1분이 소요되며, 완료 이후에는 즉시 검색됩니다. 찬양·찬송가 제목 검색은 인덱스와 무관하게 항상 즉시 동작합니다.
검색결과창에서 성경 항목을 열면 창이 닫히지 않아요.▼
의도된 동작입니다. 성경 항목은 결과창을 유지한 채 해당 절을 PC에서 열어, 같은 결과창에서 여러 구절을 연속으로 열 수 있습니다. 결과창을 닫으려면 [✕ 닫기] 버튼을 클릭하거나 Esc 키를 누르세요. 찬양·찬송가 항목은 클릭 즉시 창이 닫히고 실행됩니다.
